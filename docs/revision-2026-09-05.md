# Revisión general — 5 de septiembre de 2026

La revisión parte del árbol de trabajo existente, que ya tenía cambios amplios sin confirmar. Se han conservado esos cambios y las decisiones de stack. Esta revisión añade las correcciones descritas abajo; los controles de privacidad y las migraciones anteriores ya estaban presentes al comenzar.

## Correcciones de esta revisión

- **Sesión:** se descartan validaciones, lecturas iniciales y consultas de idioma que pertenecen a una sesión anterior. Una respuesta tardía ya no restaura un usuario después del logout ni reemplaza un token renovado por uno antiguo. Auth invalida la sesión local ante un rechazo explícito; un fallo transitorio de red conserva la sesión almacenada. La lectura inicial tiene un plazo máximo para liberar la navegación de invitados.
- **Cámara:** AR y QR ignoran permisos y coordenadas recibidos después de salir. Si MindAR termina de arrancar tarde, se ejecuta su limpieza. Un fallo de inicialización libera también los tracks de vídeo cuando el método `stop()` de MindAR falla por falta de controlador. La limpieza tolera llamadas repetidas. Cambiar el monumento remonta la experiencia y separa sus recursos.
- **Reproducción y medallas:** se muestra un error traducido con reintento si falla vídeo/audio. Reiniciar captura los rechazos de `play()`. Las medallas recibidas después de terminar el vídeo pueden mostrarse; un fallo al consultar medallas ya no se presenta como un fallo al guardar la visita.
- **Contenido ES/EN:** catálogo, monumentos cercanos, medallas, colecciones y actividad consultan las tablas de traducciones existentes. Se conservan identificadores, progreso y texto original cuando falta traducción. Las consultas agrupan y deduplican IDs, con lotes de 100. Las pantallas actualizan contenido al cambiar idioma y las vistas sociales reaccionan al cambiar de cuenta.
- **Idioma y formularios:** tiers de medallas y placeholders pasan por i18next; el contador distingue singular/plural. La etiqueta `lang` se inicializa incluso si i18next termina de arrancar antes de registrar sus listeners. La normalización tolera metadatos no textuales. La preferencia de idioma se guarda en `profiles`, evitando dos escrituras concurrentes que podían contradecirse. El login admite contraseñas antiguas aunque el alta exija ocho caracteres. Reenviar el correo recupera el botón ante excepciones.
- **Edge Function:** el límite de 2 KiB se aplica mientras se consume el stream, también sin `Content-Length`; se cancela el lector al superarlo. Se exige el tipo MIME JSON exacto, permitiendo parámetros como `charset`.
- **CI:** la prueba de integración arranca los servicios locales que necesita, además de Postgres. El script calcula la URL de funciones aunque el runtime aún no esté iniciado. Se añaden casos HTTP de tipo MIME incorrecto y cuerpo excesivo enviado por chunks.
- **Navegación:** las rutas lazy muestran el estado de carga existente al navegar, en vez de mantener la pantalla anterior sin indicar que la descarga está pendiente. Se verifica el ciclo catálogo → colecciones → catálogo con React Router real.
- **Pruebas:** se añade jsdom únicamente como dependencia de desarrollo para probar ciclos de vida reales de React, navegación y reproducción simulada; las pruebas no activan la cámara física.

## Límites y trabajo de producto pendiente

- No se ha desplegado ni modificado una base remota, ni se han confirmado cambios en Git. No se ha reseteado la base local existente.
- La cámara y el tracking deben probarse en un móvil por HTTPS con una imagen `.mind` y contenido editorial reales. Las pruebas de React simulan cámara, GPS y reproducción; no certifican compatibilidad física.
- El código recibido reproduce el vídeo como overlay tras reconocer el monumento y detiene el tracking al reproducir. El diseño de un plano `VideoTexture` anclado a la fachada sigue siendo una diferencia entre el diseño previsto y la implementación; no se ha sustituido ese flujo durante la revisión.
- Los períodos históricos aún no tienen tabla de traducciones y vídeo/audio mantienen una URL por monumento. Por tanto, traducir nombres y descripciones no equivale a tener toda la narración y cronología bilingüe.
- El seed de la colección Culiparda sólo vincula un monumento: el progreso muestra 1 aunque el objetivo editorial sea 10. Los otros nueve deben incorporarse como contenido real.
- MindAR sigue generando avisos de módulos Node externalizados y un chunk grande; se mantiene la versión de Three.js compatible. Su arranque interno no ofrece cancelación completa: si el navegador mantiene pendiente un permiso, los recursos de una inicialización tardía se liberan al finalizar ésta.
- La señal visual proviene de JavaScript y no acredita criptográficamente la presencia física. Los límites de este mecanismo están descritos en `security.md`.
